# Grouping of internal/core's non-test files into domains (WP-1664, WP-ADR151).
#
# Each line is `domain: glob glob ...`; globs match file names (path.Match).
# The first line with a matching glob wins; a file matching no line falls to
# the group named by its stem before the first underscore, and a group not
# listed here is "unplaced" and sits at the top of the order.
#
# The ORDER of the lines is the provider-first layer order, bottom first: a
# reference from a file in one group to a file in a group listed later is
# "upward" and is what has to be cut before the lower group can move out of
# core. The order is the one the core split plans to follow; change it with the
# plan, not to make a number look better.
